# OKF Curation Skill

Use this skill when converting temporary observations into durable harness knowledge.

## Process

1. Review candidate material from `okf/inbox/` or `okf/logs/`.
2. Identify whether it belongs as a concept, playbook, project memory, or should remain a log.
3. Check for duplication against existing OKF files.
4. Preserve evidence, source pointers, or decision context.
5. Prefer small updates over large rewrites.
6. Update `okf/index.md` if a major new area is added.
7. Append a note to `okf/log.md`.

## Rule

Not every observation deserves durable memory. Promote only reusable, stable, or decision-relevant knowledge.
