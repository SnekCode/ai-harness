# Skills

Skills are reusable, model-readable procedures. They are not executable tools by themselves.

Use skills for:

- Repeatable reasoning patterns
- Harness maintenance procedures
- Review protocols
- OKF curation rules
- Project bootstrap guidance

Use tools/plugins for:

- Deterministic checks
- File system operations
- Shell execution
- Policy enforcement
- Goal verification

A skill may call for tools, but the skill itself should remain portable across OpenCode, Claude Code, Codex, Gemini, and future adapters.
