# /improve-harness

Use the Harness Improvement Skill to safely change this AI Harness repo.

1. Read `skills/harness-improvement.md`.
2. Read relevant files from `core/`, `skills/`, `okf/`, `adapters/`, `scripts/`, `templates/`, and `evals/`.
3. Classify the requested change.
4. Make the smallest coherent improvement.
5. Update docs or OKF if behavior changes.
6. Run or describe relevant evals.
7. Record follow-up work.
