# OpenCode Baseline

OpenCode is the initial execution runtime for the AI Harness.

It should be treated as an adapter, not the entire harness identity. Global rules, OKF, goal schemas, and routing belong to the harness core. OpenCode-specific implementation belongs in `adapters/opencode/`.
