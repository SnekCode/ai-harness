# AI Harness

An AI harness is the owned operational layer around one or more AI models. The model provides intelligence. The harness provides context, tools, permissions, goals, verification, memory, and durable workflows.

## Principle

Own the harness. Swap the model.

## Components

- Rules and modes
- Model router
- Agent roles
- Tools and plugins
- Goal state and completion contracts
- OKF durable memory
- Evaluation suites
