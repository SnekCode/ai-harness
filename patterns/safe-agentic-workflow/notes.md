# SAFe Agentic Workflow Notes

Use SAFe Agentic Workflow as a pattern library, not as the harness runtime.

## Extract

- Hooks as automatic guardrails.
- Commands as user-invoked workflows.
- Skills as reusable model-invoked expertise.
- Role separation: orchestrator, planner, builder, reviewer, curator.
- Quality gates and stop-the-line behavior.
- Multi-provider adapter thinking.

## Avoid Initially

- Full enterprise ceremony.
- Too many agents before proven need.
- Remote autonomous server patterns.
- Process overhead that slows personal development.
